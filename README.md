Cet exercice consiste à créer un script Node.js interactif qui communique avec l'utilisateur via le terminal (invite de commande).

Le programme réalise les actions suivantes :

Pose une question à l'utilisateur dans le terminal : "Quel est le nombre : ".

Récupère la réponse saisie par l'utilisateur.

Convertit la saisie (qui est initialement une chaîne de caractères) en un type numérique (Number).

Affiche le résultat dans la console pour confirmer la valeur saisie.

Ferme l'interface d'interaction pour terminer l'exécution du programme proprement.


Assurez-vous d'avoir Node.js installé sur votre machine.

Ouvrez votre terminal dans le dossier contenant le fichier script (ex: index.js).

Lancez la commande suivante :

node index.js

Entrez un nombre lorsqu'il vous est demandé et appuyez sur Entrée.
